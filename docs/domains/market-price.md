# 시세 도메인 규칙

이 문서는 시세 계산, 체결 수집, 일봉 상태와 검증 시나리오를 정의한다.
[프로젝트 컨텍스트](../project/CONTEXT.md)는 제품 범위와 기술 결정을 요약하고,
시세 도메인의 상세 동작과 검증 기준은 이 문서를 원본으로 사용한다.

## 현재가 계산

- 경매장에 등록된 매물 중 최저 5개 고유 단가를 후보로 사용한다.
- 후보의 중앙값을 기준으로 10% 이내인 가격만 대표 가격군에 포함한다.
- 중앙값과 정확히 10% 차이 나는 가격도 포함한다.
- 대표 가격군의 산술 평균을 가장 가까운 정수 골드로 반올림한다.
- 고유 단가가 5개보다 적으면 존재하는 가격 전체에 중앙값 필터를 적용한다.
- 유효한 매물이 하나뿐이면 해당 가격을 현재가로 사용한다.
- 등록 매물이 없으면 이전 값을 사용하지 않고 `no-listings` 상태로 처리한다.
- 현재가는 1시간마다 갱신한다.

## 일봉과 데이터 상태

- 일봉은 한국 시간 기준으로 집계한다.
- 시가·고가·저가·종가는 해당 날짜의 최초·최고·최저·마지막 체결가를 사용한다.
- 체결이 없는 날은 이전 종가로 채우지 않고 빈 데이터 구간으로 처리한다.
- 당일 일봉은 `pending`으로 표시하고 자정 이후 마지막 체결을 수집한 뒤 확정한다.
- 예약 수집 실패 직후에는 `recovering`으로 기록한다.
- 다음 수집에서 연속성이 확인되면 `complete`로 복구한다.
- 연속성을 확인할 수 없으면 `incomplete`로 기록한다.
- 아직 확보하지 못한 기간은 `데이터 없음` 상태로 처리한다.
- 도메인 상태는 오류 경계가 아니라 정상 UI 안에서 표현한다.

## 수집과 보존

- 네오플 경매장 체결 데이터를 10분마다 수집한다.
- API가 100건을 반환했고 이전 수집의 마지막 거래와 연속성을 확인할 수 없으면
  해당 일봉을 `incomplete`로 처리한다.
- 수집 실패를 정상적인 무거래 구간으로 변환하지 않는다.
- 일부 실패를 성공으로 숨기지 않는다.
- 실패 상태 기록 자체가 실패하면 작업 전체를 실패 처리하고 예외를 상위 경계로
  전달한다.
- 원시 체결 데이터는 90일 보존하고 일봉 데이터는 무기한 보존한다.

## fixture

- 자동 테스트에서 실제 네오플 API를 호출하지 않는다.
- 실제 응답에서 확보한 fixture는 API 키와 식별 가능한 정보를 제거한다.
- fixture는 테스트 목적에 필요한 최소 필드를 유지하면서 실제 API 계약 형태를
  보존한다.
- 정상, 빈 응답, 최대 100건, 잘못된 응답, 중복 및 연속성 단절 fixture를 구분한다.
- 외부 API 계약 검증을 위한 제한된 실제 호출은 일반 자동 테스트와 분리한다.

## 필수 단위 및 통합 시나리오

일봉 OHLC에는 다음 시나리오를 테스트한다.

- 최초 및 마지막 체결
- 최고 및 최저 가격
- 한국 시간 날짜 경계
- 무거래 구간

중복 제거에는 다음 시나리오를 테스트한다.

- 동일 거래 재수집
- 서로 다른 거래
- 중복 식별 키가 불완전한 응답

현재가 계산에는 다음 시나리오를 테스트한다.

- 고유 단가가 5개 이상인 경우
- 고유 단가가 5개 미만인 경우
- 유효 매물이 하나인 경우
- 매물이 없는 경우
- 중앙값과 정확히 10% 차이 나는 가격
- 중앙값과 10%를 초과해 차이 나는 이상치
- 가장 가까운 정수 골드로 반올림

수집 상태 판정에는 다음 시나리오를 테스트한다.

- `pending`
- 실패 직후 `recovering`
- 연속성 복구 후 `complete`
- 연속성을 확인할 수 없는 `incomplete`
- 100건 응답에서 연속성을 확인할 수 없는 경우

보존 정책에는 다음 시나리오를 테스트한다.

- 원시 체결 데이터의 90일 경계
- 일봉 데이터가 삭제되지 않는지 여부

오류 처리에는 다음 시나리오를 테스트한다.

- 일시적 오류의 제한된 재시도
- 재시도하지 않는 오류
- 실패 상태 기록 자체의 실패

## 필수 E2E 흐름

- 데스크톱 시세 화면과 최근 30일 차트 로딩
- 모바일 레이아웃과 차트 로딩
- 기간 선택
- `매물 없음`, `pending`, `recovering`, `incomplete`, `데이터 없음` 표시
- 오류 화면의 안전한 재시도
- 오픈소스 라이선스 페이지 접근
- 키보드 접근
- 주요 텍스트 넘침

기본 브라우저 범위는 데스크톱 Chromium과 모바일 WebKit으로 한다. 브라우저별
결함이 발견되면 Firefox 또는 추가 Playwright 프로젝트로 범위를 확대한다.
