# 기여 규칙

이 문서는 이슈, 구현, 커밋과 Pull Request 작업에 필요한 세부 문서를 선택하는
진입점이다. 현재 수행하는 작업에 해당하는 문서만 읽는다.

## 작업별 문서 선택

| 작업 범위                         | 읽을 문서                                  |
| --------------------------------- | ------------------------------------------ |
| 이슈 조사, 등록, 분할, 계획, 승인 | [이슈와 계획](workflows/issues.md)         |
| 승인된 최하위 이슈 구현           | [구현](workflows/implementation.md)        |
| 커밋과 브랜치                     | [커밋과 브랜치](workflows/commits.md)      |
| PR 생성, 수정, 리뷰와 merge       | [Pull Request](workflows/pull-requests.md) |
| 코드 작성과 수정                  | [코드 컨벤션](CODE_CONVENTIONS.md)         |

한 요청이 여러 작업을 포함하면 각 작업을 시작하기 직전에 해당 문서를 읽는다. 모든
세부 문서를 미리 읽거나 현재 작업과 관련 없는 문서를 추가로 읽지 않는다.
